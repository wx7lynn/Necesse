# Necesse Map Finder

Un visualizador interactivo de mapas para el juego **Necesse**, inspirado en herramientas como Chunkbase.

## 🚀 Características
- Cálculo visual de la cuadrícula de islas basado en la semilla del mundo.
- Renderizado interactivo con HTML5 Canvas.

## 🛠️ Tecnologías
- HTML5 / Canvas
- JavaScript Vanilla
- Alojado en GitHub Pages
